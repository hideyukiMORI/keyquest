# Onboarding Training

## Goal

The first part of KeyQuest should teach home position and finger usage
relentlessly. The player should not reach the flashy RPG layer before the basic
keyboard posture starts to feel natural.

This is the foundation of the whole 90-day journey.

## Principles

- Start with accuracy and finger memory, not speed.
- Repeat home-position patterns more than a typical game would dare to.
- Keep early feedback gentle but strict.
- Teach which finger should move, not only which key should be pressed.
- Delay complex symbols until the player has stable rhythm.
- Make repetition feel like training in a fantasy academy, not punishment.

## First 7 Days

The first week is the "Novice Hall" arc.

- Day 1: home position, `f`, `j`, `a`, `s`, `d`, `k`, `l`, `;`.
- Day 2: left and right hand balance.
- Day 3: vertical finger movement from home position.
- Day 4: common home-row combinations and rhythm.
- Day 5: short English words using familiar keys.
- Day 6: weak-finger review and slow perfect typing.
- Day 7: first boss quest that checks home-row accuracy.

The first boss should reward patience. Passing with high accuracy should matter
more than typing quickly.

## Lesson Shape

Early lessons should use a tight progression:

1. Show the target keys and responsible fingers.
2. Drill small pairs.
3. Drill short patterns.
4. Drill short words.
5. Mix old and new keys.
6. End with a calm accuracy check.

Example progression:

```text
f j
ff jj
fj jf
asdf jkl;
sad lad ask fall
```

## RPG Framing

The early game should frame repetition as training:

- Home Row becomes the "Novice Stance".
- Each finger becomes a trainee guard or spell channel.
- Slow perfect input is "steady blade practice".
- Weak-finger review is "repairing the stance".

Rewards should reinforce fundamentals:

- Accuracy titles
- Stance XP
- Small focus crystals
- Unlocking the first real quest only after stable basics

## Advancement Gates

Avoid letting players skip fundamentals too early.

- New key groups unlock through accuracy thresholds.
- Speed achievements should be hidden or quiet during the earliest lessons.
- If accuracy drops, suggest a review quest before pushing forward.
- Players can keep practicing beyond the daily target, but the best rewards come
  from calm, accurate sessions.
